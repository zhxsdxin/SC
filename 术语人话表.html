一攻击与威胁

MITB Man-in-the-Browser，浏览器中间人攻击

浏览器里的内鬼

人话你在网上正常操作，黑客却通过先钻进你浏览器的恶意程序，偷看或篡改你提交的信息。它躲在你和网站之间，你和网站都看不出异常。

例子你转账给小王，木马偷偷把收款账号换成黑客的。

一句话你以为自己在操作，其实背后有人替你改数据。

MITM Man-in-the-Middle，中间人攻击

冒充邮差偷看信件

人话黑客坐在通信双方中间，冒充彼此转发消息，既能偷看内容也能动手脚，而双方以为在直接对话。

例子连了假 WiFi，你以为在跟银行服务器说话，其实是黑客的机器在转发。

一句话通信被第三方中转，机密和真实性一起丢。

XSS Cross-Site Scripting，跨站脚本攻击

往别人网页里塞私货

人话攻击者把恶意脚本塞进正常网页，别人一打开脚本就在其浏览器里跑，偷 cookie、改页面都行。

例子论坛留言没过滤内容，有人发了带脚本的帖子，谁点开谁中招。

一句话你的浏览器替攻击者执行了不该执行的代码。

CSRF Cross-Site Request Forgery，跨站请求伪造

借你的手，办你的证

人话你已登录某网站，攻击者诱导你的浏览器在不知情中带上登录凭证发出请求，冒充你办事。（与 XSS 区别：XSS 是注入脚本执行，CSRF 是冒用身份发请求）

例子登录着网银时点了钓鱼链接，后台自动触发了一笔转账。

一句话用你的身份，办你没同意的事。

SQL 注入 SQL Injection

问路时夹带私货指令

人话攻击者在输入框里塞进 SQL 片段，骗过程序直接进数据库执行，从而拖库、改数据、绕过登录。

例子登录框用户名填 ' OR '1'='1，条件恒真，直接登进别人账户。

一句话把"数据"说成"命令"，让数据库言听计从。

DDoS Distributed Denial-of-Service，分布式拒绝服务

一群人同时堵门

人话控制大量"肉鸡"同时猛刷一个服务，把带宽或资源占满，让正常用户用不了。

例子大促前对手网站被海量假流量打到打不开。

一句话不是偷你东西，是让你没法做生意。

APT Advanced Persistent Threat，高级持续性威胁

不敲门、长期潜伏的高级小偷

人话有组织、有资源、有耐心的攻击者，长期潜伏目标网络，悄悄摸清环境、窃取情报，很难被发现。

例子先钓一个员工，再一层层内网横移，潜伏数月偷走图纸。

一句话不是顺手牵羊，是盯上你、住进来的专业团队。

RAT Remote Access Trojan，远程控制木马

留了一把远程开门的钥匙

人话中招的电脑被装上木马，攻击者能远程看屏幕、开摄像头、传文件、敲键盘，像在用自己的电脑。

例子电脑被控后，黑客远程打开你的文件、录屏，再转发出去。

一句话你的电脑，别人也能用。

C&C / C2 Command and Control，命令与控制服务器

木马军的指挥部

人话僵尸网络里，被控机器（肉鸡）定期来这台服务器领指令、汇报战果；打掉 C&C，整个网络就散。

例子安全人员定位并封掉某个 C&C 域名，成片上线的木马立刻变聋哑。

一句话肉鸡的"班主任"，擒贼先擒它。

侧信道攻击 Side-Channel Attack

不看账本，看打算盘的声音和手速

人话不正面破解密码，而是从运行时的"副产品"——耗电、电磁、耗时、声音——反推密钥或明文。

例子测加密芯片每次运算的耗电波动，推算出它用的私钥。

一句话密码本身没泄，是"干活时的动静"泄了底。

钓鱼 / 社会工程 Phishing / Social Engineering

披着制服的骗子

人话不攻技术，专攻人——伪装成可信角色（银行、IT、领导），骗你点链接、交密码、给验证码。

例子收到"IT 部门"邮件说密码将过期，点进去是个一模一样的假登录页。

一句话最薄的防线，往往是坐在屏幕前的人。

二加密与认证

PKI Public Key Infrastructure，公钥基础设施

数字世界的"身份证 + 公安局"体系

人话用"证书 + 权威 CA + 一套流程"解决"这人/这网站到底是谁"，让公钥加密能安全落地。

例子浏览器地址栏的小锁，就是在用 PKI 验证网站身份。

一句话没有 PKI，公钥不知道对面是谁，等于抓瞎。

数字签名 Digital Signature

带防伪水印的签名章

人话用私钥对内容（的哈希）盖章，任何人用你的公钥都能验真伪：确认是你签的、且内容没被改过。（管"真实完整"，不管"保密"）

例子软件安装包附上官方签名，你才能确认它没被篡改、确实来自厂商。

一句话既能防冒充，又能防篡改。

哈希 / SHA Hash / Secure Hash Algorithm

文件的"指纹"

人话把任意长度数据压成一串定长"摘要"，改一个字节摘要就大变；用来校验完整性、存密码（加盐后）。

例子下载文件后比对官方给的 SHA-256，一致才放心。

一句话正向飞快、反向几乎不可能，专揪"被动过手脚"。

AES / RSA 对称加密 / 公钥加密

同一把钥匙 vs 一把锁配一把钥匙

人话AES 加解密用同一密钥，快，适合加密大量数据；RSA 用公钥锁、私钥开，慢，适合安全地送密钥或签名。

例子TLS 里先用 RSA/ECDHE 安全商定出会话密钥，再用 AES 加密正文。

一句话一个拼速度，一个拼安全交换；真用起来常搭配。

TLS / SSL

通话外面的防窃听密封袋

人话在应用和网络之间加一层，把传输内容加密、验明服务器身份、防篡改；HTTPS 就是靠它。

例子网址从 http 变 https、有了小锁，中间人看不到你填的密码。

一句话让"网上说的话"只有该听的人能听懂。

证书 / CA / CRL Certificate / Certificate Authority / Certificate Revocation List

身份证、签发公安局、挂失名单

人话CA 给网站/人签发数字证书证明身份；证书若泄露或过期就进"吊销名单(CRL/OCSP)"，别人据此不再信它。

例子某网站私钥泄露，CA 吊销其证书，浏览器立刻报警。

一句话有权威发证，也得有办法收回作废的证。

PQC Post-Quantum Cryptography，后量子密码

给密码学换一块抗地震的新地基

人话量子计算机会快速破解 RSA/ECC 等现有公钥算法，PQC 是提前研发、迁移到能扛量子攻击的新算法。

例子NIST 在标准化一批抗量子算法，供未来长期保密数据使用。

一句话今天的密文，要为明天的量子计算机提前上锁。

MFA / 多因素认证 Multi-Factor Authentication / OTP

进门要钥匙 + 指纹 + 口令

人话登录不只看"你知道的"（密码），还要"你有的"（手机/令牌动态码）或"你本身的"（指纹/人脸），多者叠加。

例子转账时除了密码，还要输入手机 App 刷新的 6 位动态码。

一句话光偷到密码，也进不来。

三邮件与 Web 防护

WAF Web Application Firewall，Web 应用防火墙

网站门口专抓可疑请求的安检门

人话守在 Web 服务器前，按规则识别并拦截 SQL 注入、XSS 之类的恶意请求，放行正常流量。

例子拦掉带 ' OR 1=1 的登录尝试，请求根本到不了数据库。

一句话给网站加一道专门挡"应用层攻击"的闸。

DKIM / SPF / DMARC 邮件防伪三件套

盖公章 + 列白名单 + 规定怎么核对

人话SPF 声明"哪些服务器能代表我发信"；DKIM 给邮件加防伪签名；DMARC 规定两者不一致时怎么处理（拒收/隔离）。

例子三者配好，伪造"你公司域名"的钓鱼邮件会被直接拒收。

一句话让"假冒发件人"的邮件现形、被挡。

HSTS HTTP Strict Transport Security

强制走加密通道，不许抄近路

人话网站告诉浏览器"以后只准用 HTTPS 连我"，堵住首次被降级成 http 的中间人劫持。

例子即使输成 http，浏览器也自动跳 https，不给窃听机会。

一句话把"能不能加密"从可选变成强制。

OP25B Outbound Port 25 Blocking，出站 25 端口封锁

封死家用宽带直连发信的后门

人话运营商封掉家庭/普通宽带的 25 号端口，逼大家走官方 SMTP 服务器发信，从源头减少垃圾/钓鱼邮件和僵尸发信。

例子在家自建邮件服务器直连外网发信发不出去，必须经服务商中转。

一句话堵住"任意电脑都能直发邮件"的口子。

DNSSEC

给域名查询结果盖防伪钢印

人话给 DNS 记录加数字签名，让解析结果可验证真伪，防"假域名劫持"把你导去钓鱼站。

例子查银行官网，DNSSEC 验证失败就拒绝返回假 IP。

一句话让"域名→IP"这一步也能验真。

四防御与监控

IDS / IPS 入侵检测 / 入侵防御系统

监控摄像头 vs 带闸机的保安

人话IDS 盯流量、发现可疑就报警（只看不动手）；IPS 更进一步，能实时拦截恶意流量（边看边挡）。

例子IDS 记录到内网扫描，IPS 直接把探测包丢掉并告警。

一句话一个只喊，一个边喊边拦。

SIEM Security Information and Event Management，安全信息和事件管理

把各地监控接到一个指挥大屏

人话汇总各设备/系统的日志与告警，关联分析，从海量线索里捞出真正的攻击链。

例子单看一台服务器没事，SIEM 关联发现"同一账号半夜从多地登录"，这才暴露入侵。

一句话把散落的线索，拼成完整的案发现场。

SOC Security Operations Center，安全运营中心

7×24 的安全值班室

人话专门的团队 + 工具，全天候监控、研判、处置安全事件，是"人 + 流程 + 技术"的运转中枢。

例子夜里 SIEM 告警，SOC 分析师连夜确认并隔离了中招主机。

一句话买一堆设备不够，得有人盯着、能动起来。

CASB Cloud Access Security Broker，云访问安全代理

云服务门口的统一安检 + 登记处

人话架在用户和云服务之间，统一做身份认证、权限、加密、审计，看清并管住"谁在用哪些云、传了啥"。

例子员工用私人网盘传公司文件，CASB 拦下并告警。

一句话让影子 IT 和云上数据也纳入管控。

防火墙 / 包过滤 / 状态检测 Firewall / Packet Filtering / Stateful Inspection

门卫从"看脸"到"看关系"

人话包过滤按 IP/端口逐包放行（不看上下文）；状态检测记住连接的来龙去脉，只放行属于合法会话的包，更聪明也更难骗。

例子外网主动进来的包默认拒，只有你先连出去建立的回包才放行。

一句话从"单个包审问"进化到"整条对话跟踪"。

五身份与访问控制

SSO Single Sign-On，单点登录

一张门禁卡刷遍全公司

人话登录一次，就能访问多个互信系统，不用每个系统各记一套账号密码。

例子用公司账号登录后，直接进邮箱、OA、代码库，无需反复登录。

一句话少记很多密码，但门户一旦失守全线沦陷。

SAML / OAuth / OIDC 身份联邦三件套

让"可信机构"替你证明你是谁

人话SAML 用签名的"断言"在系统间传递登录身份；OAuth 管"授权"（让 App 有限度代你访问）；OIDC 在 OAuth 之上补上"身份认证"。

例子用微信/公司账号登录第三方网站，就是这套在背后跑。

一句话一个管"你是谁"，一个管"你能动我什么"，别混。

RADIUS

网络准入的统一门卫

人话集中的认证/授权/计费服务器，管"谁能接进网络、能给什么权限"，常用于 WiFi、VPN、交换机准入。

例子连公司 WiFi 要过的账号校验，后台就是 RADIUS。

一句话把"进门资格"收到一处统一发落。

FIDO / 无密码认证 FIDO / Passwordless

用指纹/安全键当面验人，不靠背密码

人话基于公钥、本地生物识别或硬件安全键完成认证，服务端不存密码，天然抗钓鱼和拖库。

例子插上硬件安全键或按指纹即可登录，钓鱼网站骗不到你的凭证。

一句话没有可偷的密码，钓鱼自然失效。

RBAC / DAC / MAC 基于角色 / 自主 / 强制访问控制

按职位发权限 vs 自己说了算 vs 制度强制

人话DAC 由资源主人自己定谁能访问；MAC 由系统按密级强制管控（军政常用）；RBAC 按"角色"批量授权，最平衡、最常用。

例子RBAC 里"财务角色"一批人自动获得报销系统权限。

一句话权限交给谁定，决定了管理的松紧。

NAPT / NAT 网络 / 端口地址转换

一栋楼一个门牌，内部房间靠总机转接

人话让多台内网设备共用一个公网 IP 出门，NAPT 再用端口区分是哪台设备，顺带挡住外网直接摸进来。

例子全家设备共用一个公网 IP 上网，路由器就是靠 NAPT 分流。

一句话省 IP + 天然遮挡内网，但不等于防火墙。

VPN / IPsec

在公用马路上挖一条专用隧道

人话VPN 把远程/异地网络在公网上拉成一条加密"专线"；IPsec 是常用的那套"封装 + 加密 + 认证"协议。

例子出差连公司 VPN，像坐在办公室一样访问内网系统。

一句话公网当专线用，前提是加密和认证都到位。

六网络与基础设施

SDN Software-Defined Networking，软件定义网络

网络设备的"遥控中枢"

人话把"转发"和"控制"分开，用软件集中编程控制全网流向，不用一台台设备手动配。

例子数据中心用控制器一键调整链路策略，应对突发流量。

一句话网络从"拼硬件配置"变成"写软件调度"。

NFV Network Functions Virtualization，网络功能虚拟化

把专用机房设备换成通用服务器上的 App

人话防火墙、负载均衡等网元不再用专用硬件，改成跑在通用服务器上的软件，灵活扩容、省钱。

例子促销临时加个虚拟防火墙实例，几分钟上线。

一句话专用机柜 → 通用机房的软件，弹性至上。

CSMA/CD 载波侦听多路访问 / 冲突检测

开会时先听有没有人讲，撞车就都停下

人话以太网老规矩：发数据前先侦听线路，传输中检测冲突，撞了就退避重发，是共享介质时代的秩序。

例子老式集线器环境下两台同时说话会冲突，靠它退避重来。

一句话先听后说、边听边说、撞了就撤。

ARP Address Resolution Protocol，地址解析协议

用 IP 打听门牌号（MAC）

人话局域网内靠 IP 找对应网卡物理地址（MAC）的机制；无防护时会被"ARP 欺骗"劫持流量。

例子攻击者回假 ARP 把自己变成"网关"，同网段流量全经过他。

一句话内网的"问路协议"，也能被冒充带偏。

IoT Internet of Things，物联网

万物连上网，冰箱也上网

人话把传感器、家电、摄像头、工业设备连起来采集与控制；好处多，但设备安全性参差，常成攻击入口。

例子摄像头弱口令被拉进僵尸网络，参与大规模 DDoS。

一句话连得越多，暴露面越大，安全要从设备抓起。

七数据库

ACID 原子性 / 一致性 / 隔离性 / 持久性

转账要么全成，要么全不算

人话事务的四保证：操作不可分割（原子）、数据始终合规（一致）、并发互不干扰（隔离）、提交后永久生效（持久）。

例子扣款和到账必须同生同死，不能只扣不打。

一句话关系库事务的"金标准"。

BASE 基本可用 / 软状态 / 最终一致性

先能用，慢慢再对齐

人话NoSQL/分布式常用的取舍：保基本可用、允许中间软状态、追求最终一致，用一致性换性能和扩展性。

例子你发的评论朋友晚几秒才看到，这就是最终一致。

一句话强一致让位给高可用，讲究"差不多齐活"。

NoSQL

不按表格规矩来的数据库

人话为海量、灵活、高并发场景设计的非关系型数据库（键值/文档/列/图），schema 灵活、易横向扩展。

例子用文档库存结构多变的用户资料，不必先定死表结构。

一句话要规模和灵活，就得在强一致/事务上做取舍。

WAL Write-Ahead Logging，预写日志

先记账，后办事

人话改数据前先把"要做什么"写进日志，崩溃后靠日志重放恢复，保证持久性、支撑事务。

例子断电重启后数据库按 WAL 重放，回到崩溃前的一致状态。

一句话先留凭据，才能反悔和恢复。

DAO / DBA 数据管理员 / 数据库管理员

一个定"存什么"，一个管"怎么存稳"

人话DAO 从业务出发管数据的定义、标准、逻辑设计；DBA 管物理设计、性能、备份恢复、运行维护。

例子定字段口径和命名规范是 DAO，调慢查询、做灾备是 DBA。

一句话一个懂业务管口径，一个懂技术管跑得稳。

八系统与服务管理

VDI Virtual Desktop Infrastructure，虚拟桌面基础架构

把电脑桌面搬进机房，你只收"画面"

人话桌面跑在服务器虚拟机上，本地只传键鼠和画面；数据不落地，便于集中管控和防泄。

例子用 VDI 浏览网页，即使中招也只脏了服务器上的临时虚拟机。

一句话本地只剩一块屏幕，风险和数据都收在云端。

ITIL IT 基础架构库

IT 运维的"服务管理教科书"

人话一套 IT 服务管理最佳实践框架，讲事件/问题/变更/配置/容量等流程怎么管，让 IT 像"服务"一样经营。

例子报修走"事件管理"，反复出现的根因走"问题管理"根治。

一句话把"修电脑"升级成"经营 IT 服务"。

MTBF / MTTR / MTRS 平均故障间隔 / 平均修复时间 / 平均服务恢复时间

多久坏一次 vs 多久修好 vs 多久恢复服务

人话MTBF 看可靠性（越长越好）；MTTR/MTRS 看可维护性（越短越好），是可用性的两个抓手。

例子系统月月崩但 10 分钟恢复——可靠性差、可维护性尚可。

一句话一个防患，一个救急，合用才谈得上可用性。

SLA Service Level Agreement，服务等级协议

服务商给你打的"服务欠条"

人话和客户/供应商白纸黑字约定服务质量指标（可用率、响应时间等）和未达标的后果。

例子云服务承诺 99.9% 可用，达不到按比例赔付。

一句话把"尽量稳定"变成可考核的承诺。

RTO / RPO 恢复时间目标 / 恢复点目标

停机多久能回来 vs 能容忍丢多少

人话灾备两个核心指标：RTO 是故障后多久恢复业务；RPO 是能接受丢多长时间的数据。

例子RTO=1 小时、RPO=15 分钟，意味着要热备且近实时备份。

一句话一个定"多快要回来"，一个定"最多能丢多少"。

BCP Business Continuity Plan，业务连续性计划

公司的"灾难求生剧本"

人话预先规划重大中断（灾害、攻击、疫情）时如何保住关键业务运转，含备用场地、切换流程、演练。

例子主数据中心宕机，按 BCP 切到异地继续下单。

一句话平常不演练，出事全抓瞎。

KEDB Known Error Database，已知错误数据库

踩过的坑，记下来别再踩

人话把已知问题、根因和绕过的办法存成库，出故障时快速匹配、缩短 MTTR。

例子报"登录慢"，一查 KEDB 发现是某个已知缓存问题，直接按预案处理。

一句话把一次排查的经验，变成大家的快速通道。

RAID Redundant Array of Independent Disks，独立磁盘冗余阵列

多块硬盘组队，既提速又兜底

人话把多块盘组合起来，靠条带化提速、镜像/校验冗余，坏一两块盘数据不丢、服务不断。

例子RAID 5 坏一块盘，换新的后靠校验重建，数据完好。

一句话用多盘换性能和安全，但备份仍不能省。

RPA Robotic Process Automation，机器人流程自动化

让软件机器人替人干重复活

人话模拟人在系统里的点击录入，把规则固定的重复流程自动化，提效减错（不适合需要判断的活）。

例子每天自动登录多个系统下载报表、汇总发邮件。

一句话专治"重复、规则明确"的体力活。

SBOM Software Bill of Materials，软件物料清单

软件的"配料表 + 供应商"

人话列出一款软件用了哪些组件、版本、来源，出漏洞时能快速判断自己是否中招、影响面多大。

例子Log4j 爆发时，靠 SBOM 秒查哪些系统用了受影响版本。

一句话看不清自己用了啥，出事先慌一半。

九项目管理与挣值

EVM Earned Value Management，挣值管理

把进度换算成钱来称一称

人话用 PV/EV/AC 三个值定量看项目"计划干多少、实际干了多少、实际花了多少"，从而判断进度和成本偏差。

例子该干 100 的活只干了 80 却花了 120，一眼看出进度落后还超支。

一句话进度和成本，用同一把尺子量。

PV / EV / AC 计划价值 / 挣值 / 实际成本

计划菜单 / 真正吃到的 / 实际结账

人话PV 是到现在"计划该完成"的预算；EV 是到现在"实际完成"对应的预算；AC 是到现在"真金白银花了"多少。

例子EV<PV 进度落后，EV<AC 成本超支。

一句话三个数一比，项目好坏立现。

CPI / SPI 成本绩效指数 / 进度绩效指数

每一块钱买到的进度 / 计划 vs 实际

人话CPI=EV/AC（<1 超支）、SPI=EV/PV（<1 落后），量化"效率"和"进度"的偏离程度。

例子CPI=0.8 表示花 1 块只办成 8 毛的事。

一句话大于 1 是赚，小于 1 是亏。

BAC / EAC / ETC 完工预算 / 完工估算 / 尚需估算

原计划总价 / 预计最终总价 / 还得再花

人话BAC 是最初总预算；EAC 是预测的最终总成本；ETC 是剩下的活还要花多少（EAC = AC + ETC）。

例子按当前烧钱速度，EAC 明显高于 BAC，说明要超预算。

一句话站在现在，预测终点。

WBS Work Breakdown Structure，工作分解结构

把大工程拆成一张树状任务清单

人话把项目目标逐层分解成可分配、可估算、可交付的小工作包，是排期和分工的地基。

例子把"建网站"拆成需求/设计/前端/后端/测试等一层层任务。

一句话先拆清楚，才谈得上管得住。

PMBOK / PMO 项目管理知识体系 / 项目管理办公室

项目管理的"百科全书" / "项目管家部门"

人话PMBOK 是项目管理方法与流程的知识体系；PMO 是组织里定标准、给支持、做监督的常设部门。

例子PMO 统一模板、把关里程碑、跨项目协调资源。

一句话一个给方法，一个抓落地。

ROI / TCO 投资回报率 / 总拥有成本

这笔买卖划不划算 / 买回家一共要花多少

人话ROI 看投入产出比；TCO 把采购 + 运维 + 培训 + 能耗等全周期成本算总账，别只看标价。

例子设备便宜但电费维修贵，TCO 可能更高。

一句话一个算收益，一个算全周期的真实花费。

PPM Product Portfolio Management，项目组合管理

把一堆项目当股票组合来挑

人话站在组织层面排优先级、配资源，平衡"明星/金牛/问题/瘦狗"各类项目，把钱花在战略对的地方。

例子砍掉回报低的"瘦狗"项目，集中投"明星"项目。

一句话不是每个项目都值得做，要会挑组合。

十风险与合规

CVE / CVSS / CWE 漏洞编号 / 漏洞评分 / 缺陷类型

漏洞的"身份证" / "病危评分" / "病历分类"

人话CVE 给公开漏洞统一编号；CVSS 按利用难度和影响打 0–10 分；CWE 归纳缺陷的类型根因。

例子CVE-2021-44228（Log4Shell）CVSS 10 分，全网紧急修补。

一句话一个认人，一个打分，一个归类。

CRYPTREC

日本官方的"密码算法选用白名单"

人话日本评估并推荐政府/企业可安心使用的密码技术清单，是选型和安全施策的参考基准。

例子日本系统选算法时对照 CRYPTREC 清单，确认仍被推荐。

一句话官方替你先把密码算法把过关。

ISMAP 情報セキュリティ管理基準，日本信息安全管理基准

日本的信息安全管理"操作手册"

人话日本推动信息安全管理的基础基准，指导组织建立方针、组织、人等管理措施（对应 ISO/IEC 27001 的思路）。

例子企业按 ISMAP 搭信息安全管理体系、明确责任人。

一句话让安全管理有章可循、有人负责。

内部统制 Internal Control

公司的"自我免疫系统"

人话为保证业务有效、财务可靠、合规经营而建立的制度与流程，四目标：有效性/可靠性/合规/资产安全。

例子职责分离、审批流、留痕审计，都是内控的体现。

一句话靠制度互相牵制，防错也防坏。

个人信息保护 / PIA Privacy Impact Assessment，隐私影响评估

动用户数据前，先评估会不会伤到人

人话收集使用个人信息要合法、正当、最小化；PIA 是上新系统前评估隐私风险、定保护措施的环节。

例子上新功能前评估"是否多采了不必要的信息"，超标就改设计。

一句话先把隐私当需求，别等出事再补。

术语均取自本题库（令和元年～7年）实际出现的概念，按出现频率与重要度筛选；比喻与"人话"为帮助记忆的通俗讲解， 准确含义以原题解説及权威定义为准。术语表随题库更新可继续增补。
